# More Cultural Names

This is a mod for various strategy games that adds new place names based on their culture and faction. The names are designed to provide an immersive and historically accurate experience for each game's setting and time period.

## ✨ Capabilities

- Culturally contextual place names for immersive gameplay
- Support for multiple game titles and community mods
- Save-game compatible—add or remove without breaking saves
- Works across all operating systems supported by the game
- Actively maintained with regular updates and improvements
